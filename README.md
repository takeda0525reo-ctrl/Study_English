# Study English

高校1年生から大学受験レベルまでの **英単語** と **英文法** を学べる学習アプリです。
インストールやビルドは不要で、ブラウザだけで動きます（スマホ・PC 両対応）。

## できること

### 単語（4レベル・400語）

| レベル | 内容 |
| --- | --- |
| 1. 高1 基礎 | 高校英語の土台になる必修語 |
| 2. 高2 標準 | 教科書・模試でよく出る重要語 |
| 3. 共通テスト・入試標準 | 共通テストや中堅大で差がつく語 |
| 4. 難関大 | 難関国公立・私大の長文で問われる語 |

- **おすすめ学習** … 習熟度に合わせて「英→日 4択」→「日→英 4択」→「スペル入力」へ自動でステップアップ
- **形式を選んで練習** … 英→日 4択 / 日→英 4択 / スペル入力 / フラッシュカード
- **単語一覧** … 意味・例文・学習状況の確認、検索、絞り込み
- すべての単語に例文と和訳つき。発音の読み上げにも対応（ブラウザの音声機能を使用）

### 文法（15単元・120問）

文型 / 時制 / 完了形 / 助動詞 / 受動態 / 不定詞 / 動名詞 / 分詞・分詞構文 / 関係詞 / 比較 / 仮定法 / 接続詞 / 前置詞 / 否定・倒置・強調 / 名詞・代名詞・形容詞

- 各単元に **解説**（要点と例文）と **演習**（4択の空所補充 + 語句の並べ替え）
- 1問ごとに和訳と解説を表示

### 復習と記録

- 単語は正解するたびに復習の間隔が延びる（1日 → 3日 → 7日 → 14日 → 30日）間隔反復方式
- 「今日の復習単語」「苦手な単語」「文法の間違えた問題」をまとめて解き直し
- 今日の学習数・連続学習日数・7日間の学習量をホームに表示
- 学習記録はブラウザ（localStorage）に保存。設定画面から書き出し・読み込みが可能

## 使い方

`index.html` をブラウザで開くだけで動きます。

ローカルサーバーで動かす場合:

```bash
python3 -m http.server 8000
```

その後 `http://localhost:8000` を開きます。

### GitHub Pages で公開する

リポジトリの **Settings → Pages** で、公開するブランチとフォルダ（`/ (root)`）を選ぶと、
`https://<ユーザー名>.github.io/Study_English/` でスマホからも使えるようになります。

## ファイル構成

```
index.html            画面の土台
css/style.css         デザイン（ライト / ダーク対応）
js/app.js             アプリ本体（画面・出題・記録）
js/data/words.js      単語データ
js/data/grammar.js    文法データ（解説と問題）
tools/validate.js     データのチェック用スクリプト
```

## 単語・問題を追加する

### 単語

`js/data/words.js` に1行追加します。

```
英単語|品詞|意味|例文|例文の和訳
```

例: `achieve|動|を達成する|She worked hard to achieve her goal.|彼女は目標を達成するために懸命に努力した。`

### 文法問題

`js/data/grammar.js` の各単元の `qs` に追加します。

```js
// 4択（a は正解の番号。0 から数える）
{ t: "c", q: "I ( ) in Tokyo since 2015.", c: ["live", "lived", "have lived", "am living"], a: 2, ja: "和訳", ex: "解説" }

// 並べ替え（w に正しい順で語句を並べる。画面ではシャッフルされる）
{ t: "o", ja: "和文", w: ["I", "have", "never", "seen", "it"], ex: "解説" }
```

### 追加したらチェック

形式の間違いや単語の重複を確認できます（Node.js が必要）。

```bash
node tools/validate.js
```
